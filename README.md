# Transparens er ikke så vanskelig

Lysbildene til Alexander Refsum Jensenius' innlegg "Transparens er ikke så vanskelig, vi har alt vi trenger for fornuftig bruk av KI" på Forum for forskningsetikk ved Universitetet i Oslo.

Se presentasjonen: https://pages.github.uio.no/alexanje/forskningsetikk-2026/

## Innlegget

Ti minutter, på norsk. Påstanden er at det viktigste forskningsetiske grepet med kunstig intelligens er mer åpenhet, og at verktøyene for å få det til allerede finnes: versjonskontroll, tidsstempler, varige identifikatorer (DOI og ORCID), siteringsfiler og arbeidslogger gjør det mulig å dokumentere hva som er gjort av mennesker og hva av maskiner. Det vi ikke har kontroll på, er innholdet i svart-boks-modellene, særlig de kommersielle, og derfor trenger vi egne modeller med innsyn i treningsdata.

Innlegget handler om forskerutdanningen: når maskinene kan levere produktet, må vi lære bort og vurdere prosessen. Det har fire kapitler: veiledning er kvalitetskontroll, dokumenter prosessen, vurder prosessen og kjenn modellen (der også at verktøyet ikke er modellen, og at modellene skifter, så versjonsnummeret må med), og slutter med tre råd til stipendiater og veiledere og med hvordan presentasjonen ble laget. Nederst i hver stabel ligger mer stoff til panelet.
